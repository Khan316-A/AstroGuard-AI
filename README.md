# 🚀 AstroGuard AI: Autonomous Astronaut Health Monitoring System
**Built for NASA Space Apps Challenge 2026 (Faisalabad)**

## Overview
AstroGuard AI is a real-time telemetry and medical alert dashboard designed for deep-space astronauts. It monitors heart rate, SpO2, cabin CO2, and cosmic radiation against official NASA Human Research Program (HRP) thresholds.

## NASA Data Used
- **NASA Human Research Program (HRP):** Used physiological baselines for microgravity heart rate, hypoxia thresholds, and acute radiation exposure limits.
- **NASA Open Science Data Repository (OSDR):** Referenced spaceflight environmental telemetry parameters.
